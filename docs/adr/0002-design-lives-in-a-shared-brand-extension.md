# The Brand lives in a shared brand extension

The site's colours and fonts live in a Quarto brand extension in its own repo, `slangenbach/slangenbach-brand`, not in this repo. The site and every personal Deck install it with `quarto add` and pin a release tag. Keeping the extension in this repo would have been simpler, but Decks live in their own repos and need the same colours and fonts without copying the site's SCSS. The brand holds only what both media use: element styling (blockquotes, code blocks, links) and site layout stay in this repo's SCSS, and each Deck styles its own slides. Fonts load from Bunny Fonts, since Quarto 1.10 doesn't copy brand font files into reveal.js output. A Deck uses the brand of whoever Stefan speaks for, so Talks given for byteCare keep bytecare-brand.
